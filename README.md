# HU connect（MACアドレス取得テスト版）

micro:bit V2 と Grove UART WiFi V2 用の MakeCode 拡張機能です。

## 追加したブロック

「Wi-FiモジュールのMACアドレスを問い合わせる」ブロックを追加しました。

- コマンド欄の初期値は `wifi_mac` です。
- これは現在のESP8285/RoboBlocks系ファームウェアで有効と確認されたコマンドではありません。
- ファームウェアが未対応の場合は `invalid_command` などが返る可能性があります。
- このブロックはコマンドを送って応答を表示する診断用です。ファームウェアを書き換えるものではありません。

## 試し方

1. MakeCodeでこの拡張機能を読み込みます。
2. Grove UART WiFi V2の通信端子を設定します。
3. 「Wi-FiモジュールのMACアドレスを問い合わせる」ブロックの戻り値を、LED表示またはシリアル出力で確認します。
4. `invalid_command` が返った場合、`wifi_mac` は未対応です。別のコマンドを推測で連続実行せず、ファームウェアの対応コマンド仕様を確認してください。

既存のWi-Fi接続、WebSocket接続、文字列・数値送信ブロックは維持しています。
